# El caminante sobre un mar de nubes

El caminante deambula por el planeta, contemplando nubes.

## Descripción

Aplicación web en la que el 'El caminante sobre un mar de nubes' de Caspar David Friedrich deambula por el planeta contemplando centros de datos.

## Referencias

Obra basada en la pintura 'Caminante sobre un mar de nubes, Caspar David Friedrich, Óleo sobre tela, 1818'

Conjuntos de datos obtenidos de: 

- https://www.peeringdb.com/
- https://www.datacenter-atlas.com/

Imagen del caminante tomada de: https://wanderer.cdfriedrich.de/
